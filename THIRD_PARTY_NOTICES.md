# Third-party components

Spooky Treat Station bundles the following, so it can run fully offline:

|---|---|---|
| MediaPipe Tasks Vision 0.10.21 (Google) | `web/vendor/mediapipe/` | Apache License 2.0 |
| EfficientDet-Lite0 object detection model (MediaPipe) | `web/models/efficientdet_lite0.tflite` | Apache License 2.0 |
| Pose Landmarker Lite model (MediaPipe) | `web/models/pose_landmarker_lite.task` | Apache License 2.0 |
| Creepster font (Font Diner, Inc) | `web/fonts/creepster.woff2` | SIL Open Font License 1.1 |
| Luckiest Guy font (Astigmatic) | `web/fonts/luckiest-guy.woff2` | Apache License 2.0 |

The release packages (Windows and Linux) also contain the offline natural-voice engine (downloaded by `scripts/fetch-voices.sh`, not stored in this repository):

|---|---|---|
